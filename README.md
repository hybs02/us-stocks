# 米国株 中長期スクリーナー

S&P500 の全銘柄を1日4回自動で採点し、決めた規則で「月末の見直しで売る候補・買う候補」をスマホに出す個人用ツール。
数ヶ月〜1年の保有を前提にした規則。API キーは要らない。

画面: https://hybs02.github.io/us-stocks/ （開いて「ホーム画面に追加」）

売買を勧めるものではない。下の数字は過去データでの検証で、生存バイアスで実際より良く出ている（「数字の見方」）。使うかどうかは自分で判断する。

## 使い方

| やること | 方法 |
| --- | --- |
| 見る | 上の画面を開く。↻ を押すと GitHub API から最新を直接読む（raw は5分キャッシュされるため） |
| 今すぐ採点し直す | GitHub の Actions タブ →「daily-scan」→ Run workflow |
| 手元で採点する | `python scan.py`（標準ライブラリだけで動く。data.json と chart.json ができる） |

## しくみ

```
GitHub Actions（UTC 15:41・18:41＝米国の取引中／21:41・01:41＝引け後。月〜金）
  └ scan.py が約500銘柄を採点して data.json（結果）と chart.json（1年の値動き）を作る
      ├ data 枝に毎回上書き（force push）
      └ 構成銘柄の一覧 sp500.csv が変わっていれば main にコミット
          └ 画面は raw.githubusercontent.com/hybs02/us-stocks/data/ から読むだけ
```

- 構成銘柄は毎回 datasets/s-and-p-500-companies から最新を取る（指数の入れ替えもそのまま入る）。
- 取引中の値は途中の値なので、月末の点数には使わない（scan.py の `live` 判定）。
- data.json・chart.json を main に置かない（何度もコミットすると main の履歴が膨らみ続ける）。
- GitHub の定時実行は混むと遅れたり飛ばされたりする。

## 規則（ツールが候補を出す決まり）

| 項目 | 内容 |
| --- | --- |
| 点数 | 6ヶ月の値上がりの順位×50% ＋ 200日線からの離れ具合の順位×30% ＋ 12-1ヶ月の値上がりの順位×20%（0〜100） |
| 見直し | 月に1回、月末の点数で |
| 売る候補 | 持ち株のうち、月末の点数が 70 未満のもの |
| 買う候補 | 月末の点数 70 以上・200日線の上・財務に地雷なし、を点数順に。同じ業種は5つ・同じ細かい業種は2つまで。合計10銘柄 |
| 新規を止める | S&P500（SPY）が月末に 200日線の下なら、新しく買わない（持ち株は上の規則のまま） |

値は `scan.py` の `W_MOM6`・`W_TREND`・`W_MOM12`・`BUY_MIN`・`SECTOR_CAP`・`SUB_CAP`・`PORTFOLIO`。

### 財務の扱い

ROE・営業利益率・負債・PER は地雷を避けるフィルタだけに使い、順位には使わない（過去の一時点のデータが取れず検証できない）。

| 弾く条件 | |
| --- | --- |
| 営業赤字 | 営業利益率 < 0 |
| ROE マイナス | ROE < 0 |
| 借金が多い | D/E > 300% |
| 株価が利益の100倍超 | PER > 100 |

次の決算発表日も画面に出す。

## 数字の見方

銘柄リストが「いまの」S&P500 なので、過去に脱落した企業が入っていない（生存バイアス）。
下の数字は全部、実際より良く出ている。規則どうしの比較（同じ偏りを共有）には使えるが、利益率をそのまま期待できる数字ではない。

## 検証（research/・2006〜2026・手数料込み）

```bash
python research/fetch_hist.py sp500.csv research/sp500_latest.csv   # 2004 年からの日足を research/cache/ に取る
python research/study_rules2.py
```

検証スクリプトは numpy を使う。売買は月末の終値で採点し、翌営業日の終値で約定する。

| ファイル | 中身 |
| --- | --- |
| `research/fetch_hist.py` | 日足（調整後終値）を取る。取ってある銘柄は飛ばす |
| `research/study_rules.py` | 何を・いつ売るかの規則を20年分で比べる |
| `research/study_rules2.py` | 売るしきい値 × 見直しの頻度 × 銘柄数 × 相場フィルタ（往復手数料 1.3%） |
| `research/sp500_latest.csv` | 検証に使う構成銘柄の一覧（`sp500.csv` と合わせて読む） |

### 売り方（10銘柄・毎月見直し・往復手数料1.3%・`study_rules2.py`）

| 売り方 | 年率 | 最大下落 |
| --- | --- | --- |
| 同じ銘柄群を均等に持つ（基準） | 15.7% | −48.9% |
| 点数 40 未満か 200日線割れで売る | 27.9% | −59.0% |
| 点数 50 未満で売る | 28.9% | −59.2% |
| 点数 70 未満で売る | 32.7% | −57.8% |
| 点数 80 未満で売る | 30.8% | −60.0% |
| 70 未満で売る ＋ S&P500 が 200日線の下なら新規を止める（採用） | 31.6% | −32.6% |
| 70 未満で売る ＋ S&P500 が 200日線の下なら全部売る | 24.2% | −34.0% |

| 比べたもの | 結果 |
| --- | --- |
| 高値から −15〜30% で売る逆指値 | どれも成績を下げた（`study_rules.py`） |
| 見直しの頻度 | 毎週 29.0%／毎月 32.7%／3ヶ月ごと 29.6% |
| 銘柄数 | 5 は 34.8%（値動きが荒い）／10 は 32.7%／15 は 26.1%／20 は 22.7% |
| 2006〜2012 年 | どの売り方も基準を 2〜4% 下回った（2009 年の反発局面でモメンタムが負ける、よく知られた弱点） |

### 点数の中身（20年・毎月5分位）

| 要因 | 6ヶ月後の差 | t値 | 採否 |
| --- | --- | --- | --- |
| 6ヶ月モメンタム | +2.86% | 3.70 | 採用（50%） |
| 200日線からの乖離 | +2.40% | 2.89 | 採用（30%） |
| 12-1モメンタム | +1.72% | 1.91 | 採用（20%） |
| 低ボラティリティ | −8.16% | −8.40 | 不採用（生存バイアスの疑い） |
| 短期リバーサル（逆張り） | −1.45% | −1.90 | 不採用 |
