# 米国株 中長期スクリーナー

S&P500 の全銘柄を1日4回自動で採点し、「月に1回の見直しで何を売って何を買うか」をスマホで確認できるツール。
数ヶ月〜1年の保有を想定しています。

**スマホ用**: https://hybs02.github.io/us-stocks/ （開いて「ホーム画面に追加」）

## しくみ

```
GitHub Actions（1日4回：米国の取引中2回・引け後2回。GitHub の混雑で遅れたり飛んだりすることがある）
  └ scan.py が約500銘柄を採点して data.json（結果）と chart.json（1年の値動き）を作る
      └ data 枝に毎回上書き（main の履歴を膨らませないため）
          └ スマホは raw.githubusercontent.com/hybs02/us-stocks/data/ から読むだけ（APIキー不要・↻ を押した時は GitHub API から直接）
```

構成銘柄の一覧は毎回最新を取りに行きます（以前は 7 月の一覧のままで、入れ替えが反映されていなかった）。

## 規則

| 項目 | 内容 |
|---|---|
| 点数 | 6ヶ月の値上がりの順位×50% ＋ 200日線からの離れ具合の順位×30% ＋ 12-1ヶ月の値上がりの順位×20% |
| 見直し | **月に1回、月末の点数で**（毎週見直すより良かった） |
| 売る | 持ち株の**月末の点数が 70 未満** |
| 買う | 月末の点数 70 以上・200日線の上・財務に地雷なし、を点数順に。同じ業種 5 つ・同じ細かい業種 2 つまで。合計 10 銘柄 |
| 止める | **S&P500 が月末に 200日線の下なら、新しく買わない**（持ち株は上の規則のまま） |

## 検証（`research/`・2006〜2026・手数料込み）

`python research/fetch_hist.py sp500.csv research/sp500_latest.csv` でデータを取ってから実行します。

### 売り方（10銘柄・毎月見直し・往復手数料1.3%）— `study_rules2.py`

| 売り方 | 年率 | 最大下落 |
|---|---|---|
| 同じ銘柄群を均等に持つ（基準） | 15.7% | −48.9% |
| 以前のアプリ（点数 40 未満か 200日線割れで売る） | 27.9% | −59.0% |
| 点数 50 未満で売る | 28.9% | −59.2% |
| **点数 70 未満で売る** | **32.7%** | −57.8% |
| 点数 80 未満で売る | 30.8% | −60.0% |
| **70 未満で売る ＋ S&P500 が 200日線の下なら新規を止める（採用）** | **31.6%** | **−32.6%** |
| 70 未満で売る ＋ S&P500 が 200日線の下なら全部売る | 24.2% | −34.0% |

- 高値から −15〜30% で売る逆指値は、どれも成績を下げた（`study_rules.py`）
- 見直しの頻度：毎週 29.0% ／ **毎月 32.7%** ／ 3ヶ月ごと 29.6%
- 銘柄数：5 は 34.8%（値動きが荒い）／ **10 は 32.7%** ／ 15 は 26.1% ／ 20 は 22.7%
- 2006〜2012 年はどの売り方も基準を 2〜4% 下回った（2009 年の反発局面でモメンタムが負ける、よく知られた弱点）

### 点数の中身（2026-07 の検証・20年・毎月5分位）

| 要因 | 6ヶ月後の差 | t値 | 採否 |
|---|---|---|---|
| 6ヶ月モメンタム | +2.86% | 3.70 | 採用（50%） |
| 200日線からの乖離 | +2.40% | 2.89 | 採用（30%） |
| 12-1モメンタム | +1.72% | 1.91 | 採用（20%） |
| 低ボラティリティ | −8.16% | −8.40 | 不採用（生存バイアスの疑い） |
| 短期リバーサル（逆張り） | −1.45% | −1.90 | 不採用 |

## ⚠ 数字の見方（重要）

銘柄リストが「いまの」S&P500 なので、過去に脱落した企業が入っていない（生存バイアス）。
**全部の数字が実際より良く出ています。** 規則どうしの比較（同じ偏りを共有）には使えますが、
示された利益率をそのまま期待しないでください。

## ファンダメンタルズの扱い

ROE・利益率・負債・PER は「地雷を避けるフィルタ」だけに使い、順位には使いません
（過去の一時点データが取れず検証できないため）。弾く条件: 営業赤字 / ROE マイナス / D/E>300% / PER>100倍。
次の決算発表日も表示します。
